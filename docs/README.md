# OctoAcme Project Management Docs

This README indexes the OctoAcme project management process documents and provides a short summary of the processes used by the OctoAcme team to help with discoverability and onboarding.

## Project management processes summary

- Initiation: capture the problem, stakeholders, and a Project One-pager to decide whether to plan work.
- Planning: prioritize and estimate the backlog, define the Definition of Done (DoD), and map releases and milestones.
- Execution & Tracking: use project boards (Backlog → Ready → In Progress → In Review → QA → Done), keep PRs small and include acceptance criteria, run CI tests, and follow a regular team rhythm (standups, weekly syncs, demos).
- Release & Deployment: perform pre-release checks, run smoke tests in staging, deploy via automated pipelines when possible, and have rollback/mitigation plans.
- Retrospective & Continuous Improvement: capture learnings, create action items with owners and due dates, add improvements to the backlog, and measure impact.
